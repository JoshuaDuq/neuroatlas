# Workspace organization

The user rejected the previous workbench organization and identified too many
panels and scattered controls as the main problem. Keep the clinical visual
world and scientific behavior; replace the workspace structure.

- Use two columns: one 320px task panel and the remaining width for anatomy.
- Give the task panel four destinations: Explore, Region, Sections, View.
- Open region details on a new selection while exploring. Keep Sections and
  View active when selecting anatomy during those tasks. Return to Explore
  when the last contextual selection is cleared.
- Consolidate specimen, cortical atlas, appearance, internal detail,
  hemisphere, and visibility controls in View. Keep the header to identity,
  current source, image capture, fullscreen, and a settings menu.
- Preserve the phone sheet with the same four destinations and existing
  camera inset and detent behavior. Remove the stacked tablet rails.
- Verify state transitions, keyboard navigation, anatomy search, sections,
  display, Circuits, and English/French layouts at desktop, tablet, phone,
  narrow phone, landscape phone, and the user's 522px panel width.

Reference: WAI-ARIA Authoring Practices, Tabs Pattern
https://www.w3.org/WAI/ARIA/apg/patterns/tabs/

Direction: one control surface, a stable generous anatomy view, and contextual
details in the same panel. The scientific scene leads; navigation has one home.
