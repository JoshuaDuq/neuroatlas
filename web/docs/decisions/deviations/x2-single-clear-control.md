# One clear control in the search field

Chunk: X2
Status: fix (standard cited)

## Legacy behaviour

A `type=search` field shows the browser's own cancel button beside the custom Clear search button.

## New behaviour

The browser's cancel button is hidden; the custom button, with a name and a 44 px coarse target, is the only one. It returns focus to the field.

## Standard cited

Decision 38 (D9) on #4; WCAG 2.2 SC 3.2.4 Consistent Identification.
