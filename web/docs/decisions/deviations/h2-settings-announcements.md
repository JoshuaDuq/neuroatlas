# Setting changes are announced

Chunk: H2
Status: fix (standard cited)

## Legacy behaviour

Choosing a language, theme or single-key setting says nothing; the panel closes and focus lands on More settings.

## New behaviour

Each change is announced through the polite live region as "<row label>: <choice>" in the language in force after the change ("Theme: Dark", "Langue : Français"), built from the existing header strings.

## Standard cited

WCAG 2.2 SC 4.1.3 Status Messages.
