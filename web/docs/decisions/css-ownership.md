## Layer contract

`src/styles/index.css` declares `@layer tokens, base, elements, components, features, a11y;` before anything else, and `src/main.ts` imports it before any component, so the statement leads the bundled CSS (`src/styles/layer-order.test.ts` builds a probe component to prove it).

- Svelte scopes component selectors with a class, so a component rule outranks an element rule by specificity. Layers, not source order, decide between layers: a later layer wins whatever the specificity.
- Every component `<style>` rule is inside a top-level `@layer components` (shared widgets in `src/lib/ui/`), `@layer features` (panels, stage, masthead) or `@layer a11y`. Only `@keyframes`, `@property` and `@font-face` may sit outside a layer.
- Layers are never nested: a nested `@layer a11y` inside `components` would create the sublayer `components.a11y`, which ranks below `features` and below the top-level `a11y`.
- Forced-colours and `prefers-contrast` rules sit directly in the top-level `@layer a11y`: `@layer a11y { @media (forced-colors: active) { ... } }`.
- Hover styles sit inside `@media (hover: hover) and (pointer: fine)` (or its negation, `@media not ((hover: hover) and (pointer: fine))`) and nowhere else.
- `!important` inverts layer order (the earliest layer wins). Only `base.css` uses it (`[hidden]`, theme swap, `data-instant`), where winning over every later layer is the intent. A reduced-motion rule that must beat a component transition is written without `!important` in `@layer a11y`.
- Every `var(--x)` without a fallback names a declared token (`src/styles/stylesheets.test.ts` checks every stylesheet and every `<style>` block).
- Line heights come from `--lh-caption|ui|prose|title`.
